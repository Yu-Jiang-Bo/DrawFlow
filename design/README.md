# Web Prototype V1

本目录是制图渲染 Web MVP 的设计审核稿，不是前端实现。

## 原型图

- `web-prototype-render-task-v1.svg`：出图任务页
- `web-prototype-template-management-v1.svg`：模板管理页
- `web-prototype-render-task-v2.svg`：出图任务页 V2
- `web-prototype-template-management-v2.svg`：模板管理页 V2

## 本版设计取向

- 用户上传订单表格，不填写本机路径。
- 用户上传 `.ai` 模板，不填写服务端已有路径。
- 页面不展示内部技术字段、调试参数和任务文件路径。
- 部门规则以中文业务说明展示。
- 渲染完成后自动下载 `.ai` 文件。
- 模板管理支持多 `.ai` 资产上传，适配复杂设计拆分。
- 模板规则以自然语言/表单化方式录入，系统生成结构化规则预览，人工确认后保存。

## 待审核点

- 出图任务页是否符合仓库同事的日常操作顺序。
- 模板管理页字段是否足够同事维护模板。
- 出图任务页是否还需要显示模板状态，还是只保留最近任务。
- 多 `.ai` 资产分类是否覆盖复杂模板拆分方式。
- 自然语言规则说明是否需要接入 LLM 生成配置草稿。
- 结构化规则预览是否足够让同事审核。
